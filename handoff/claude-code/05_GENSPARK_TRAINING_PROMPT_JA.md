# Genspark用 研修LPメーカー作成プロンプト

ユーザーが指定した既存ページ:

https://owojchhi.gensparkspace.com/index.html

Gensparkに貼るプロンプト案:

```text
既存のページ https://owojchhi.gensparkspace.com/index.html に、研修資料LPメーカーの管理画面を追加してください。

目的:
社内研修、歯科医院スタッフ研修、営業研修、マニュアル共有に使える、資料ページを簡単に作成・公開できる管理システムにしたいです。

必要機能:
1. 研修一覧
2. 研修新規作成
3. 研修編集
4. セクション追加/並び替え/削除
5. 画像・動画・PDFアップロード
6. タイトル、説明文、所要時間、対象者、カテゴリ設定
7. 公開/非公開切替
8. 公開URL発行
9. 複製
10. 受講完了チェック
11. スマホでも読みやすい公開ページ

UI要望:
- 日本語
- 初心者でも迷わない
- 管理画面は業務ツールとして洗練された見た目
- 編集画面は上から順に入力すれば完成する構成
- ファイルアップロードはドラッグ&ドロップ対応
- 公開URLとプレビューがすぐ確認できる

公開ページ:
- スマホファースト
- 画像/PDF/動画を見やすく表示
- セクションごとに読みやすく区切る
- 下部に「受講完了」ボタン
- 研修資料として清潔感あるデザイン

想定ユーザー:
- 歯科医院スタッフ
- 広告会社のクライアント
- 社内研修担当者

完成イメージ:
Notionのように編集しやすく、Canvaのように直感的で、研修資料としてそのまま配れる品質。
```
