# 次にClaude Codeへ依頼する作業プロンプト

このプロンプトをそのままClaude Codeに貼ってください。

```text
Swipe LP Makerをさらに商品レベルに磨き込みたいです。

最優先は「編集しやすさ」です。
広告会社に月額1万円で売れるように、LP編集画面を直感的で洗練されたUIにしてください。

やってほしいこと:

1. LP編集画面のUX改善
   - 編集画面を開いたら、まず画像追加・画像一覧・並び替えが上に出る
   - 公開URL、公開/非公開、プレビューは常にわかる位置に置く
   - タブで「スライド」「CTA」「設定」「タグ」を分ける
   - 1枚1枚が独立しすぎている感じをなくし、一覧で編集できるようにする
   - 削除、並び替え、CTA設定を迷わないUIにする

2. アップロード改善
   - 複数画像をまとめてアップロード
   - 上限を見える化
   - 失敗時にどのファイルがなぜ失敗したか表示
   - 5枚アップロードで落ちないようにする
   - 20枚まで安全に扱えるようにする

3. 公開LP表示の改善
   - スマホで黒帯が不自然に出ない
   - 縦長LP画像はフル幅で切らずに見せる
   - 通常画像は画面いっぱいにきれいに見せる
   - PCでは全画面表示できる
   - CTAエリアが画像表示に合わせてずれない

4. UIデザイン改善
   - ログイン画面、一覧、編集画面をもっとおしゃれで洗練された感じにする
   - ただし装飾過多ではなく、業務ツールとして使いやすくする
   - 日本語文言を自然にする

5. バグチェック
   - `npm run typecheck`
   - `npm run build`
   - 文字化けチェック
   - 本番/ローカルで主要導線を確認

注意:
- 秘密情報はGitに入れない
- Supabase DB変更が必要ならSQL migrationを追加する
- 変更後はGitHub mainへpushし、Vercelで反映確認する
```
