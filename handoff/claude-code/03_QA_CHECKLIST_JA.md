# QAチェックリスト

## ログイン

- ログイン画面が日本語でわかりやすい
- パスワードログインできる
- ログアウトできる
- 未ログイン時にダッシュボードへ入れない
- Magic linkやパスワード再設定の文言が日本語

## LP一覧

- LPが一覧に出る
- 公開/非公開ステータスがわかる
- 画像枚数が正しい
- 公開URLが押せる
- 編集ボタンがわかりやすい
- 複製ボタンがわかりやすい
- 余白や謎の空ボタンがない

## LP編集

- 編集画面を開いて落ちない
- 上部に公開URLと公開/非公開がある
- 最初に画像追加/並び替えが見える
- タブ切替がわかりやすい
- 設定、タグ、CTAが分離されている
- 保存後に成功表示が出る
- エラー文言が日本語

## アップロード

- 1枚アップロードできる
- 5枚アップロードして落ちない
- 20枚上限が見える
- 21枚以上はわかりやすく止まる
- 画像10MB超はわかりやすく止まる
- 動画120MB超はわかりやすく止まる
- アップロード中の進捗が見える
- 失敗したファイルだけ理由が見える
- 既存画像は消えない

## 並び替え

- ドラッグで並び替えできる
- 上下ボタンで並び替えできる
- 保存後に順番が反映される
- リロードしても順番が残る

## 削除

- 画像削除ボタンが見える
- 削除前に確認がある
- 削除後に一覧から消える
- Storage上の不要ファイルも可能なら消す
- 削除しても他画像の順番が崩れない

## CTAエリア

- 画像内CTAエリアを追加できる
- 位置/幅/高さを編集できる
- 個別URLを設定できる
- fallback CTA URLが効く
- 公開LPで透明リンクが正しい場所に乗る
- 縦長LP画像でもCTA位置がずれない

## 公開LP

- `/lp/[slug]` が表示される
- 非公開LPは見られない
- スマホで黒帯が不自然に出ない
- 縦長LP画像はフル幅で見やすい
- 通常スライド画像は画面いっぱい
- 縦スワイプが自然
- scroll-snapが効く
- CTAリンクが押せる
- 固定CTAオン/オフが効く
- Meta Pixel / GAタグが入る

## PC表示

- 公開LPで「スマホ枠」「画面いっぱい」「全画面」を切り替えられる
- 画面いっぱい表示が初期値
- 全画面ボタンが動く

## 研修資料管理

- Supabaseに `0003_training_courses.sql` が反映済み
- `/dashboard/trainings` が500にならない
- 新規作成できる
- セクション追加/編集/削除できる
- ファイルアップロードできる
- 公開URL `/training/[slug]` が表示される

## 速度/安定性

- 初回表示が遅すぎない
- 画像5枚でも編集画面が落ちない
- 画像20枚でも許容範囲
- 保存中に二重送信しにくい
- 本番でconsoleエラーがない
